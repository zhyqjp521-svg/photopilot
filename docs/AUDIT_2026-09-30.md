# 本次优化与验证

基线：`f6e8dbd`；本次修改尚未提交或推送。

## 修复

- 浏览器导入不再把原图压到 2560px JPEG，保留原始字节、扩展名和尺寸。
- XMP 合并保存已有 Lightroom 参数、关键词；原子写入；损坏文件不覆盖；自动评分尊重手动星级。
- 空目录、读取目录异常收敛到终态；错误明确显示；旧轮询不得覆盖新的扫描。
- 精扫增量以独立游标传递，已收到的终态不重复发送整库；原地更新 Map/卡片，等分相似组不穿插。
- 重新分组清除过期重复标记；取消精扫会撤销排队任务。
- 修复 CLI 批量白平衡对字符串误用 `.path` 的崩溃；自动参考统计保留 WB 后的语义。
- 批处理不再长期保存每张 1024px 图像，流式保留小型统计；成品只执行一次追色/美化。
- 编辑人脸检测使用一个固定工作线程，避免每个 HTTP 滑杆请求创建新的 FaceMesh。
- 本地文件接口拒绝外站 Origin 和非本机 Host（DNS rebinding）。

## 功能与界面

- 单张大图编辑：曝光、对比度、高光、阴影、冷暖、饱和度；实时前后预览与显式成品导出。
- 可选原始尺寸/4096/2560/2048px，JPEG 质量可选；会话分目录避免覆盖，PNG 保持 PNG。
- JSON 参数保存/载入；多张可套用同一组原创参数；失败与成功数量分别统计，失败可重试。
- 四图比较支持联动滚轮缩放、拖动平移和适合画布；保留加星。
- 延续现有布局，缩小部分过大圆角；补充状态朗读、键盘焦点与开关可访问性。
  本次 UI 调整使用 Impeccable 的 harden/optimize 检查，未更换整套视觉风格。

## 性能口径

`scripts/bench_edit.py`：M1、本机 3000×2000 测试 JPEG → 2048px 成品，自动曝光+磨皮，
每版本独立进程顺序运行三次，固定无人脸结果以隔离渲染，包含图片读写，不包含人脸推理。

| 版本 | 三次耗时（秒） | 中位数 |
|---|---|---|
| 基线 | 5.83 / 4.97 / 4.44 | 4.97 |
| 本次 | 4.91 / 2.84 / 3.08 | 3.08 |

这个样例中位耗时减少约 38%；不是所有机型/RAW/原始尺寸的速度承诺。
流式内存回归另验证 9 张处理时存活解码图数量 ≤5；不是进程 RSS 恒定的承诺。
