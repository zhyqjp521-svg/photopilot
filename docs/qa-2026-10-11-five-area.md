# 五项优化验收记录（2026-10-11）

## 范围

1. 1200 张以上的分组与普通排列按可见窗口创建卡片；缓存上限控制为 720 个，窗口最多 480 个。保留轻量分组标题，不宣称全部标题也做了虚拟化。
2. 会话内选择、星级、项目移除、手动分组撤销/重做。星级以 XMP 写入成功为准；本地废纸篓不在此撤销范围。
3. 严格/均衡/宽松扫描；目录、比例、首帧及邻帧检查，阻止链式误合并；允许人工拆组/合组。
4. 2–4 张对比：同步缩放/平移、活动窗格 0–5 星与保留/排除、适应与 100% 预览像素。
5. 自动曝光强度校验与提亮后高光压缩；验证预览/冻结导出处理和断盘、文件变化、重启队列恢复。

## 已执行测试

- Python unittest：192 项通过。
- 前端 VM：147 项通过，包括迟到评分、撤销和保存回执的项目切换隔离。
- 独立对比 VM：9 项通过。
- 安装版 Chrome 的隔离页面测试：通过 6000 张/2000 组远端跳转、普通排列最后一张、窗口缩放、6000 张单组最后一行、真实键盘撤销/重做、三种密度、筛选与隐藏选择确认、折叠与导航、当前窗格星级和 100% 预览像素。
- 合成远端跳转：原实现约 7428ms、4392 张卡片；优化后最近一次约 1220ms、12 张卡片，多次测量约 337–1499ms。运行间有波动，这不等于实际 RAW 解码吞吐量。
- 后端、前端规格与代码质量独立审核均通过，最终质量结论 APPROVED。审核发现的并发星级/移除历史、旧撤销跨项目续写、旧星级污染新快照、无关组标记变化、缓存追色目标和末组导航均已先复现后修补。

## 隔离与限制

浏览器 API 写入均为测试替身；后端文件测试仅使用临时目录，没有改动用户照片。真实项目服务未用于本次浏览器测试，使用离线图像夹具。没有重启当前原生应用，没有承诺已打开窗口已经加载这些代码。

相似分组是文件名顺序 + dHash 启发式，并非拍摄时间/语义模型。100% 预览最长边 2200，不等于 RAW 原始像素。相同分辨率的预览/导出在编码前像素一致，不能推断不同尺寸逐像素一致。已剪切纯白的源图细节不能通过自动曝光恢复。

未加入第三方 LUT、商业预设、竞争产品素材或新模型权重。检测器的两处 missing-src 提示都是运行时加载的图片：隐藏蒙版和插入前设置 src 的对比图，并非静态占位图片。
